# Proposal

## Why

V7 completed registration without a lead or a demonstrated evidence plateau: all supported families were baseline-sufficient and routing/continuity lacked bound runtime adapters. The original lead target remains unmet, so a bounded successor must test new, independent fixtures and either establish the preregistered evidence plateau or continue valid candidate search.

## What Changes

- Add matched, recorded routing and native compaction/handoff adapters, with capability-specific no-inference preflights; classify either family as unsupported with the exact failed observation when its native behavior cannot be established.
- Register one successor campaign that binds V7 and every prior result root and cumulative stop counters before inference, preserves original thresholds and frozen controls, and uses newly authored fixtures and disposable candidates only.
- Preregister a prospective plateau rule based on repeated, valid, independent baseline screens; baseline sufficiency alone will not satisfy it.
- Preserve all prior registrations, trials, reports, and the default/current-personal controls.

## Capabilities

### New Capabilities

- `personal-prompt-experiment-adapters`: Confined actor trials expose only frozen, matched routing and continuity capabilities whose execution evidence is retained.

### Modified Capabilities

- `workflow-behavior-evaluation`: Campaign lineage, cumulative counters, and evidence-plateau decisions are preregistered and cannot be reset or inferred from baseline sufficiency alone.

## Impact

`scripts/prepare_personal_prompt_eval.py`, focused Python tests, the private campaign under `target/personal-prompt-eval/`, and this change's OpenSpec delta. No global prompt, credential, provider configuration, shared daemon, or publication path changes.
