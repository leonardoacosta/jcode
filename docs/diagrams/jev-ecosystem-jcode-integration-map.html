#1 · evaluate Tool · Adopt Now

Effort: Low · Risk: Low · Impact: High

Add a native Rust evaluate tool that wraps the TypeSafe API. Every Jcode agent gets typed probabilistic judgments — no more "ask LLM then parse prose."

Start HereMCP Tool

API call

POST https://api.typesafe.ai/v1/systemone
Authorization: Bearer <TYPESAFE_API_KEY>

{
  "state": "Help! Payouts failing for 3 days.",
  "model": "jev-latest",
  "questions": {
    "is_urgent": { "type": "noul", "instructions": "Does this convey urgency?" },
    "department": { "type": "choice", "instructions": "Which team?",
      "criteria": { "billing": "Payment issues", "technical": "Bugs" } }
  }
}

Integration paths

Option A — Bundle evaluate (Go binary) as built-in MCP server. One command: evaluate setup mcp. Agents get it automatically.

Option B — Native Rust tool (~200 lines). No external dependency. Uses reqwest to call the HTTP API directly. Serde types for request/response.

Fallback: return error message if Jev is unavailable. Never block agent on Jev.

#2 · Jev Compaction · Implement

Effort: Medium · Risk: Medium · Impact: High

Replace/supplement Jcode's LLM-based context summarization. Jev scores each tool call: keep, truncate, or drop. Never rewrites anything — user and assistant text stays verbatim.

How fast-jev-compaction works

1. Pair tool_use ↔ tool_result; pin recent N messages
2. Fit state into 25k tokens (progressive truncation)
3. For each call: two Noul questions — keep call? keep result?
4. merge decisions: keep both / keep call+truncate / drop
5. Rebuild message list; no orphaned results

Jcode integration

Jcode already has compaction at agent/compaction.rs. Add JevCompactor as alternative. Gate on Jev availability; fall back to LLM summarization. Each compaction saves both cost and preserves critical details that summaries lose.

#3 · Jev Browser Selection · Steal Architecture

Effort: High · Risk: Medium · Impact: High

Jev Ultrafast proves: DOM snapshot → Jev picks operation + element → browser executes. 7.1s flight searches. 101 browser calls instead of 1,092. The architecture to steal:

Pattern

page → DOM snapshot → indexed element table
→ One TypeSafe request: operation (CLICK/TYPE/...) + target [#N]
→ Browser executes on matching element
→ Only TYPE_TEXT triggers a small LLM
→ Repeat

Jcode hook

Jcode's tool/browser.rs uses a Firefox bridge. Add action="jev_select" that takes a natural-language goal, runs the DOM snapshot, sends to Jev, and executes. Fall back to existing action-based commands if Jev is unavailable.

#4 · Jev Model Routing · Consider

Effort: Medium · Risk: Medium · Impact: Medium

On each user turn, Jev decides: simple work → fast/cheap model, complex work → strong model. Can implement as provider middleware rather than proxy.

Tiers: Fast (Haiku/Luna) / Balanced (Sonnet/Terra)

Key policy: explicit user requests win. Low confidence never downgrades. Failures keep current model. Large conversations refuse downgrades.
