Three changes that matter

  1. Structural: lost context. Render transcript and status behind the decision surface.
  2. Surface: flat hierarchy. Separate labels from descriptions, focus from selection, and advice from answers.
  3. Structural: opaque automation. Explicit overnight opt-in, visible countdown, human takeover and durable decision records.

Alternatives

Composer pane, recommended by Jcode: best narrow-terminal fit. Long content scrolls.
True overlay: smaller layout change, still obscures context.
Sidebar: good on wide terminals, poor at 80 columns.

Jev advice is not user consent

Live Jev MCP evaluation returned HTTP 404. No Jev verdict is claimed here. Proposed successful state: “Jev recommends [option] · model confidence [value]”. Proposed overnight state: “Auto-answer in 04:59 · disable”. Values are illustrative, not actual evaluation results.

New overnight runs enable eligible automation by default. Direct user instructions can opt out, and a disable control remains available. Only explicitly delegated, reversible local choices qualify. Unknown risk, sensitive decisions, partial answers and unavailable advice stay manual. Every automatic answer appears in the final run review.

Approval choices

All stages approved on 2026-09-24, revised to implicit enablement for new overnight runs with prompt opt-out. No production changes have been made.
