Chapter 02 · conversation alignment

Label the
thread.

Lanes are temporary conversational coordinates: ask for three lanes, get three named threads, and reply against a stable label.

Temporary protocol

01 / CONTRACT

Count means threads.

When the user says “three lanes,” Jcode starts three distinct discussion threads. Every response identifies the lane being addressed. If more than one project is active, the response begins with the project name before the lane label.

1

One label per thread

L1, L2, and L3 remain stable until the temporary conversation ends or the user renames them.

2

Project prefix when needed

Jcode · L2 makes the response target obvious when another project is being discussed simultaneously.

02 / ALIGN

Conversation, not authority.

Diagram fallback: a request for three lanes becomes three stable, labeled conversation threads. They can inform a decision, but they do not become a repository ledger by themselves.

How replies line up.
