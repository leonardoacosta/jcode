Chapter 01 · command lifecycle

One trail,
one authority.

Jcode separates discovery, contract authoring, and execution so evidence can advance without letting conversation memory become authority.

Approved design

01 / WHY

Separate thinking from mutation.

/explore gathers and ranks evidence. /feature resolves uncertainty and writes one implementation-ready authority. /apply executes one approved feature; /apply:all executes only an explicitly selected ordered queue.

Explore

Eight phases collect context, inspect integrations and telemetry, synthesize options, and produce one default route.

Feature

Classifies uncertainty, inventories surfaces, selects exactly one durable authority, validates, and independently reviews it.

Apply

Claims approved work, implements in dependency order, verifies final bytes, persists results, and closes truthfully.

02 / FLOW

The authority handoff.

Diagram fallback: exploration feeds one feature contract. The user authorizes either single-feature apply or an explicit queue. Verification and persistence precede any human acceptance or routing change.
