Layer · memory

Memory

Durable facts, preferences, corrections, source maps, receipts, OpenSpec artifacts, and Recon findings restore context across sessions.

Previous Back to Atlas

What this layer does

The memory layer carries reusable knowledge forward while preserving that repository evidence outranks recollection. It restores context, not authority by itself.

Daily use

A future session recalls a preference or source-map hint, then reopens the repository evidence before making a claim or edit.

Interfaces

Inputs are validated facts, preferences, corrections, and receipts. Outputs are recall hints and restored context for the next run.

Ownership

Owned by durable memory records and their correction process. Source files remain canonical for implementation truth.

Failure boundaries

Stale memories, overbroad facts, unsupported claims promoted to fact, sensitive retention, or evidence that cannot be replayed.
