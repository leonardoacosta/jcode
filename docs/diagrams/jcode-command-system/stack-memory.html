What this layer does

The memory layer turns the surrounding stack into an observable unit of work. It defines what enters the layer, what leaves it, and which evidence proves the handoff.

Daily use

Claude Code surfaces repo instructions. Codex contributes implementation loops. Pi supplies lightweight subagent patterns. Jcode coordinates native tools. Cross-agent review joins the layer when risk rises.

Interfaces

Memory stores concise reusable facts while repository evidence remains canonical; recovery reconstructs state from durable artifacts rather than recollection.

Ownership

Ownership stays with the documented Jcode command-system microsite. OpenSpec remains authority for approved behavior while implementation pages explain it.

Failure boundaries

Stale or overbroad memories, unsupported claims promoted to fact, sensitive transcript retention, or evidence that cannot be replayed to its source.
