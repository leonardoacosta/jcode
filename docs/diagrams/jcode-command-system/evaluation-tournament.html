02 / BLOCKS

Parallel without confounding.

Diagram fallback: a content-addressed descriptor freezes models, fixtures, seeds, budgets, caches, and judges. Provider-aware blocks run independently. Deterministic checks precede blind judges. Immutable evidence informs a separate human decision.

03 / DESCRIPTOR

The run is a contract.

{
  "seed": 424242,
  "cache_policy": {"strata": ["cold", "warm"]},
  "concurrency": {"per_provider": {"anthropic": 1, "openai": 1}},
  "stop_conditions": ["spending-cap", "missing-telemetry", "safety-boundary"],
  "provider_confound_threshold": "excerpted from descriptor when present",
  "deterministic_cap": "all blocks must pass before judges",
  "power_budget": {"trial_repetitions": 1, "total_spending_cap_usd": 10.0}
}
Safety: trials cannot make payments, change credentials, deploy, message third parties, or perform destructive operations. Missing auth, telemetry, calibration, isolation, or pricing fails the affected phase closed.
