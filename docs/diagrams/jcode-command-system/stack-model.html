What this layer does

The model layer turns the surrounding stack into an observable unit of work. It defines what enters the layer, what leaves it, and which evidence proves the handoff.

Daily use

Claude Code surfaces repo instructions. Codex contributes implementation loops. Pi supplies lightweight subagent patterns. Jcode coordinates native tools. Cross-agent review joins the layer when risk rises.

Interfaces

The routing registry maps roles to available OAuth, API, or Azure-backed model routes and escalates only when the role contract requires it.

Ownership

Ownership stays with the documented Jcode command-system microsite. OpenSpec remains authority for approved behavior while implementation pages explain it.

Failure boundaries

Cheap-first retries that waste budget, unavailable provider auth, self-review on high-risk work, or a model receiving authority its role does not own.
