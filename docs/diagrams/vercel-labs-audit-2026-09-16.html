Architecture: The Three-Guardrail Loop

Catalog ← you define (Zod schemas) Components { Card, Metric, Chart, Table, … } Actions { export, refresh, navigate, … } │ │ catalog.prompt() → system prompt ▼ LLM ← AI generates (constrained to catalog) Generates JSONL stream (SpecStream) {"op":"add","path":"/elements/card-1",…} │ │ streamed RFC 6902 patches ▼ Registry ← you implement (platform-native) Card → <Card> React component Metric → <Metric> │ │ <Renderer spec={spec} registry={registry} /> ▼ React | Vue | Svelte | Solid | RN | Remotion react-pdf | react-email | Ink | r3f | Next.js TanStack Start | image 18 renderers from same spec

json-render Risk Profile
Single-maintainer: ctate = 79% of commits. If Vercel reallocates or he leaves, the project could stall.
React 19 + Zod 4 gates: cardscope-admin has React 19.1.0 but no Zod. Install zod@^4 first.
Protocol fragmentation: json-render, A2UI (Google), and OpenUI solve overlapping problems with incompatible formats. A2UI v1.0 is a candidate release.
Open issue #9: json-render interoperability with A2UI — 5 comments, no resolution.
