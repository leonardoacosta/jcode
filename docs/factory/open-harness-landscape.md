# Open harness landscape

> Status: external research

- **Pi:** minimal, self-extensible agent toolkit with unified provider API, agent core, coding CLI, and explicit external sandboxing.
- **Hermes Agent:** persistent operator-oriented runtime with tools, skills, and delegation.
- **OpenClaw:** always-on personal-agent gateway with channels, extensions, and automation.
- **OpenCode:** polished open, provider-neutral coding agent and terminal harness.
- **Goose:** extensible agent platform centered on tools, MCP, and organizational integrations.
- **OpenHands:** self-hosted developer control center with local, remote, cloud, and ACP-compatible backends.
- **SWE-agent / mini-SWE-agent:** bounded repository-task workers optimized for reproducibility and evaluation.

The useful comparison is architectural, not consumer-product ranking. Shells optimize the worker loop; platforms optimize deployment and integration; task factories optimize bounded evaluation; Jcode is combining these with durable orchestration and supervision.
