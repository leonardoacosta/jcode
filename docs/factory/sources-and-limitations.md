## Limitations

This documentation is not a benchmark, a complete implementation audit, or a claim that every external project has identical capabilities at every revision. External repositories evolve. Current Jcode claims are bounded by source inspection and should be revalidated when implementation changes. Missing runtime evidence is marked as a gap rather than inferred.
