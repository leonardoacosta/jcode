# Feedback and learning

> Status: proposed closed loop

Every meaningful failure should be classified as specification, context, tool, environment, reasoning, evaluation, policy, or coordination failure. The classification should feed the smallest useful improvement: a clearer requirement, a new skill, a tool fix, an isolation change, a regression test, or a routing rule.

The factory improves when failures become durable evidence rather than disappearing into chat history. Learning must remain reviewable and must not silently rewrite production behavior.
