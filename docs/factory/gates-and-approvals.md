# Gates and approvals

> Status: proposed control model

Gates are evidence-backed transition conditions. Typical gates include formatting, linting, type checks, tests, builds, security checks, architecture checks, browser checks, runtime evidence, evaluation, diff review, and deployment health.

Approval packets should contain the proposed action, reason for escalation, affected files/tools, evidence, risk, reversibility, deadline, and available actions. Human review belongs at impact and uncertainty boundaries, not after every routine tool call.
