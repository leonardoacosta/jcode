# Evaluation and regression

> Status: external research and proposed Jcode direction

Evaluate both:

- **Outcome:** did the result satisfy requirements, tests, behavior, and acceptance criteria?
- **Trajectory:** did the worker stay within scope, use approved tools, recover from errors, preserve evidence, and obey policy?

Benchmark scores are not product acceptance. Repository tasks need representative tests, browser or integration journeys where relevant, and regression cases generated from real failures. Evaluation findings must not silently mutate production routing or policy.
