
# Rationalization Prevention

Every excuse below has previously talked a model past the verification gate. None of them are
new arguments — they're the same handful of moves in different words.

| Excuse | Reality |
|--------|---------|
| "Should work now" | RUN the verification |
| "I'm confident" | Confidence ≠ evidence |
| "Just this once" | No exceptions |
| "Linter passed" | Linter ≠ compiler |
| "Agent said success" | Verify independently |
| "I'm tired" | Exhaustion ≠ excuse |
| "Partial check is enough" | Partial proves nothing |
| "Different words so rule doesn't apply" | Spirit over letter — paraphrases and implications count |

If the excuse in front of you isn't a literal row match, check whether it's a paraphrase of one
before treating it as a genuine exception — "the tests were passing an hour ago" is "should work
now" wearing a timestamp, not a new argument.
